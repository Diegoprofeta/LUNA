Optional ambient music for LUNA

LUNA works without this file. To add background music, copy ambient.adp from
this folder into APP_LUNA on your PS2 memory card. The installed path should be
mc0:/APP_LUNA/ambient.adp (or mc1:/APP_LUNA/ambient.adp if LUNA is on slot 2).

Copy only ambient.adp into APP_LUNA. Do not copy this add-on folder there.

This is a 20-second stereo loop in native PS2 ADPCM format. Use the supplied
file; renaming a WAV, FLAC, or another ADPCM file will not convert its format.
